# Contributing

Thank you for considering a contribution to PyForestScan QGIS.

This project is intended to become production-quality scientific software and a
professional QGIS interface for PyForestScan. Contributions should prioritize
maintainability, reproducibility, testability, documentation, and respect for
the independent evolution of PyForestScan.

## Before Contributing

- Read [Project Vision](docs/PROJECT_VISION.md).
- Read [Architecture](docs/ARCHITECTURE.md).
- Read [Contributing Guide](docs/CONTRIBUTING_GUIDE.md).
- Review relevant ADRs in [docs/adr](docs/adr).

## Development Expectations

- Keep plugin interface code separate from PyForestScan computational logic.
- Add or update tests for behavior changes.
- Document user-facing behavior and architectural decisions.
- Avoid adding heavy runtime dependencies without an ADR.
- Prefer small pull requests with clear scientific or usability scope.

## Code of Conduct

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
