# PyForestScan QGIS v0.2.0-beta.4

`0.2.0-beta.4` completes the processing-control, concurrency, and Folder clipping corrections requested after beta.3. All earlier versioned artifacts remain immutable.

## Corrections

- Automatic mode uses a shared limit of up to five workers. Multiple LiDAR sources fan out across files; one source with multiple selected products fans out across products.
- Folder mode can clip every selected product to explicit rectangular XY bounds or the current QGIS map extent. Preflight skips known non-intersecting sources and grid/storage planning uses the clipped area.
- Pause stops new files and products from starting after the active safe boundary. Resume continues the retained job.
- Cancel is polled while products are active, stops queued work, terminates only plugin-owned managed-backend child processes, and retains completed outputs and summaries.
- Mouse-wheel page navigation no longer alters combo-box or numeric values under the pointer. Values still change through deliberate typing, clicking, or keyboard input.
- Live elapsed time, progress, step, file, and product reporting from beta.3 remains enabled.

## Qualification

- Complete plain-Python regression suite.
- QGIS 3.44.13 construction/unload and navigation lifecycle smoke.
- QGIS runtime button and wheel-event checks.
- Real bounded single-source, multi-product execution producing DTM and Point Density rasters concurrently inside the requested extent.
- Installed-ZIP validation and clean-profile QGIS smoke are required before distribution.
