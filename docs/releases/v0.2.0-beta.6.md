# PyForestScan QGIS v0.2.0-beta.6

This release adds a Mission Control **Voxel Statistic** product. Select `Intensity` with `mean`, `max`, or `count` to create an intensity raster, or select another available point-array field and supported aggregation.

Polygon Area Processing now registers a selected footprint index into its active catalog during preflight and keeps progress determinate with a current stage and percent rather than an indeterminate animation.

Install only the versioned `pyforestscan_qgis-v0.2.0-beta.6.zip` artifact. This beta does not overwrite prior versioned ZIPs.
