# PyForestScan QGIS v0.1.0-beta.3

Internal beta focused on bounded large-area CHM processing.

## Included

- Source-aware CHM planning for EPT, COPC, and LAS/LAZ repositories.
- Bounded EPT requests against one logical `ept.json`; internal nodes are never scheduled.
- Native small-source grouping and logical subdivision of unusually large sources.
- Aligned CHM cores, verified checkpoints, genuine resume, transient retry, transactional mosaic, and exact final mask.
- HAG suitability/strategy records and deterministic collinear-ground handling.
- Cause-preserving timeout and heartbeat progress semantics.

## Limitations

Only CHM has a partition policy. Other products retain existing paths. Automated structural/scheduler validation passes, but live CHM numerical equivalence, network performance, pause/cancel interaction, and seam analysis remain pending. External Worker mode remains disabled.

Artifacts: `dist/pyforestscan_qgis-v0.1.0-beta.3.zip` and `dist/pyforestscan_qgis.zip`.
