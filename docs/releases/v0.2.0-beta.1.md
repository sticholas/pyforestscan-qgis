# PyForestScan QGIS v0.2.0-beta.1

`0.2.0-beta.1` is a productization beta, not RC1. It consolidates the durable managed processing architecture, source-aware Folder and Polygon workflows, eight release-facing products, compact Mission Control, semantic scientific settings, and installed-package compatibility auditing developed since `0.1.0-beta.3`.

## Verified In This Drop

- Deterministic ZIP packaging, source parity, clean replacement simulation, import graph, and release validation.
- Mission Control startup, teardown, navigation, engine-state presentation, and narrow-width construction under QGIS 3.44.13 and QGIS 4.0.0.
- Semantic hover/focus help and accessible names for all 84 controls visible in default page states on both keystone runtimes.
- QGIS-free scientific contracts, state ownership, spatial handling, processing durability, and output behavior suites.
- Exact bounded EPT CHM canary: 4,393,782 points and SHA-256 `9c8d9c3ad11cebde5814c5df0222dca63c37326a78617058919d38756dfcdcee`.

## Important Limits

- Windows QGIS 3.44.x remains the supported target with documented limitations.
- QGIS 4.0 is UI-COMPATIBLE only; engine, provider, Prerun, loading, and science qualification remain open.
- Linux and macOS engine installation and science are unqualified.
- Micromamba artifacts need fixed URLs and verified SHA-256 values before RC1.
- The final-package real-LiDAR matrix, long-job controls/recovery, clean engine install, and exact CHM canary must be repeated before RC1.
- External Worker mode remains disabled.
