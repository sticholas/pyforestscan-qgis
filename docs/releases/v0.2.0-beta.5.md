# PyForestScan QGIS v0.2.0-beta.5

`0.2.0-beta.5` fixes a processing-start failure discovered in a real small-file run after beta.4. All earlier versioned artifacts remain immutable.

## Correction

- The processing monitor now accepts a heartbeat only when its embedded job ID matches the active job.
- A retained heartbeat from an earlier inspection can no longer make a newly launched job fail immediately as stalled.
- Dataset inspection jobs now receive unique IDs and result paths, preventing collisions when the same source or source folder is processed repeatedly.

## Evidence

- The reported 14.3 MB LAS run failed in about 0.45 seconds with `No heartbeat for 7372 seconds`; no scientific product had started.
- Its retained heartbeat belonged to `pbm-dataset-inspection-KNP1_full`, not the new `KNP1_clipped18mRTK_thinned` inspection.
- Runtime identity comparison matched every recorded engine, executable, protocol, manifest, and build field, ruling out a mixed-runtime launch.
- Regression tests cover both stale-heartbeat rejection and unique inspection identity.
