# PyForestScan QGIS v0.2.0-beta.2

`0.2.0-beta.2` is a reliability maintenance release based on the exact pre-viewer `0.2.0-beta.1` lineage. It does not replace or rename the earlier artifact.

## Reliability fixes

- Local LAS/LAZ DTM and Point Density requests now honor bounded reads.
- DTM output metadata uses the exact requested resolution and aligned raster extent.
- Point Density no longer requires unrelated HeightAboveGround preparation and retains exact XY point-count reconciliation.
- Managed HAG checkpoint publication matches the PyForestScan 0.4.1 list-of-arrays writer contract.
- PAD Derivative, Normalize Heights, and Preprocess Point Cloud now execute through the managed Processing Engine instead of importing scientific dependencies into QGIS Python.
- Toolbox preparation keys, Point Density defaults, and the optional PointSourceID field now match their runtime contracts.

## Qualification

- QGIS 3.44.13 loads the provider and registers all 14 algorithms.
- All 14 Processing Toolbox entry points completed against bounded real LAS/LAZ or retained EPT fixtures.
- The QGIS lifecycle smoke completed 100 construction/unload and 100 navigation/state cycles without scientific imports in the QGIS process.
- The complete QGIS-free regression suite and release validation must pass for the packaged commit recorded in the ZIP manifest.

## Artifact identity

The release artifact is `pyforestscan_qgis-v0.2.0-beta.2.zip`. Historical versioned ZIPs must not be overwritten. The shared-drive `Y:` package location is not a build destination for this maintenance release.
