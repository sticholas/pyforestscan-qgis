# PyForestScan QGIS v0.2.0-beta.3

`0.2.0-beta.3` is a processing-experience and crash-resilience correction. It preserves beta.1 and beta.2 as immutable historical artifacts.

## Corrections

- Processing now displays a live percentage, elapsed timer, current step, current LiDAR file, and current scientific product.
- Folder jobs publish the product name before each long scientific calculation and publish completion afterward.
- Worker callbacks no longer force nested Qt event processing, avoiding re-entrant completion handling.
- Batch rasters load only once after the terminal result is registered.
- A new QGIS project with no layers automatically adopts the first valid output raster CRS before results load. Existing projects keep their assigned CRS.
- Generated-output registry records now carry detected raster CRS metadata.

## Spatial-reference behavior

The source CRS remains authoritative when embedded or discovered. A new empty project follows that detected CRS automatically. Existing projects are never silently reassigned. Truly unreferenced source coordinates still require an explicit assignment because guessing would produce spatially incorrect science.
