# PyForestScan QGIS v0.1.0-beta.1

## Summary

`v0.1.0-beta.1` is an internal beta ZIP release for controlled QGIS testing. It packages the current Mission Control, Advanced Processing Toolbox, batch workflow, workspace foundation, and PyForestScan Backend Manager planning architecture into a versioned, traceable artifact.

## Key Capabilities

- Guided Mission Control for single-dataset workflows.
- Workspace resume/history foundation with local `.pyforestscan/` metadata.
- Dataset Explorer reports with footprint preview.
- Scientific Advisor and Product Planner.
- Processing workflow and Results page.
- Sequential batch and guarded Parallel Safe batch with preflight, manifests, checkpointing, resume, and retry failed files.
- Advanced Processing Toolbox groups for Diagnostics, Input / I/O, Preprocessing / Filters, Terrain, and Metrics.

## Implemented Products

- CHM.
- Canopy Cover.
- PAD.
- PAI.
- FHD.
- Rumple summary.
- Point Density.
- Voxel Statistic.
- DTM.
- Height Above Ground / normalization paths.

## PyForestScan Backend Manager Status

PBM includes user-local backend path resolution, dependency registry, verification, QGIS compatibility reporting, manifest-driven install previews, production installer architecture, structured logs, repair planning, and Windows internal beta transaction mechanics.

Windows internal beta builds can install the managed backend into the user-local PyForestScan folder after confirmation. Linux/macOS installation remains planned/experimental until platform smoke testing is complete. PBM does not modify QGIS Python, QGIS install folders, PATH, shell profiles, system Python, or user environment variables.

## Installation Notes

Build and validate from the repository root:

```bash
python3 scripts/package_plugin.py
python3 scripts/validate_plugin_package.py dist/pyforestscan_qgis.zip
python3 scripts/validate_release.py
```

Install `dist/pyforestscan_qgis-v0.1.0-beta.1.zip` or `dist/pyforestscan_qgis.zip` through QGIS Plugin Manager: **Plugins > Manage and Install Plugins > Install from ZIP**.

After installation, open Mission Control and run Environment Check before processing data. With PBM backend `Ready`, Environment Check should report overall `READY` and list QGIS Python scientific packages as optional fallback status.

## Rollback / Remove

Use QGIS Plugin Manager to uninstall PyForestScan. If manual cleanup is needed, remove `pyforestscan_qgis` from the active QGIS profile plugin directory. Generated run folders and workspaces are user data and are not removed by uninstalling the plugin.
