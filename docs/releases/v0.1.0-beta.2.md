# PyForestScan QGIS v0.1.0-beta.2

## Summary

`0.1.0-beta.2` is the internal beta release candidate for the simplified Mission Control workflow with the working Windows PBM backend installer and PBM-routed processing path.

## What Changed Since v0.1.0-beta.1

- PBM backend installation is available for Windows internal beta builds after explicit confirmation.
- PBM verifies a complete managed geospatial runtime and writes READY config only after staged and final verification pass.
- Dataset Explorer local inspection and PBM-routed products can run without installing PyForestScan or PDAL into QGIS Python.
- Environment Check reports execution readiness instead of legacy QGIS-Python-only readiness.
- Mission Control is simplified for beta users: Home is a dashboard, Environment is PBM-first, Processing shows the active backend, Results are output-first, and Batch is organized as Discover Files, Preflight, Run Batch.
- Technical logs, fallback dependency details, advanced PBM information, and batch tuning are collapsed by default.

## Key Capabilities

- Guided Mission Control for single-dataset workflows.
- Workspace resume/history foundation with local `.pyforestscan/` metadata.
- Dataset Explorer reports with footprint preview.
- Scientific Advisor and Product Planner.
- Processing workflow and Results page.
- Sequential batch and guarded Parallel Safe batch with preflight, manifests, checkpointing, resume, and retry failed files.
- Advanced Processing Toolbox groups for Diagnostics, Input / I/O, Preprocessing / Filters, Terrain, and Metrics.
- PBM backend install, verification, repair guidance, and managed execution routing for supported internal beta workflows.

## Installation Notes

Build and validate from the repository root:

```bash
python3 scripts/package_plugin.py
python3 scripts/validate_plugin_package.py dist/pyforestscan_qgis.zip
python3 scripts/validate_release.py
python3 scripts/prepare_github_release.py --dry-run
```

Install `dist/pyforestscan_qgis-v0.1.0-beta.2.zip` or `dist/pyforestscan_qgis.zip` through QGIS Plugin Manager: **Plugins > Manage and Install Plugins > Install from ZIP**.

After installation, open Mission Control, install or verify the PBM backend from Settings, then run Environment Check. With PBM backend `Ready`, Environment Check should report overall `READY` and list QGIS Python scientific packages as optional fallback status.

## Known Limitations

See [Known Limitations](../KNOWN_LIMITATIONS.md), [Clean Machine ZIP Smoke Test](CLEAN_MACHINE_SMOKE_TEST.md), [No-Manual-Setup Beta Smoke Test](NO_MANUAL_SETUP_BETA_SMOKE_TEST.md), and [Dependency State Matrix](DEPENDENCY_STATE_MATRIX.md). Key release limitations:

- External Worker mode remains disabled.
- PBM backend installation is enabled for Windows internal beta only; Linux/macOS remain planned/experimental until smoke tested.
- Height Above Ground point-cloud export and Preprocess Point Cloud still require QGIS Python dependencies until routed through PBM.
- Scientific outputs require visual QA before interpretation.
- Public QGIS Plugin Repository submission has not started.
