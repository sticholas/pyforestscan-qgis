# Release Candidate Feature Matrix

Status meanings: **READY** is release-gated, **BETA** works with stated live QA
limits, **ADVANCED** is supported for expert use, and **DEFER** is outside RC scope.

| Feature | Status | Release note |
| --- | --- | --- |
| Plugin ZIP install and identity verification | READY | Clean default-profile install/parity gate exists. |
| Automatic Windows Processing Engine setup/repair | BETA | Tested internal-beta route; pinned Micromamba digest remains a public-release gate. |
| Folder mode | BETA | PBM routed; standard runtime-token parity still has a documented limitation. |
| Polygon mode | BETA | EPT large-area baseline completed; full Phase 32Q/32R 109-region rerun remains pending. |
| LAS/LAZ | BETA | Supported; ordinary files may require source scans for bounded work. |
| COPC | BETA | Native inputs supported; automatic conversion is deferred. |
| EPT | BETA | Bounded network execution, checkpoints, adaptive isolation, and exact finalization supported. |
| CHM | READY | Core guided/routed product with real canary evidence. |
| Canopy Cover | READY | Routed product; release smoke remains required on final package. |

| PAI | BETA | Routed product; clean-package smoke required. |
| FHD | BETA | Routed product; clean-package smoke required. |
