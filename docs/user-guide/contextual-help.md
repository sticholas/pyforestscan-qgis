# Contextual Help

Mission Control uses small blue information badges beside controls whose meaning, consequence, or scientific interpretation is not obvious.

Hover a badge for a short tooltip. Click or focus the badge and press Enter or Space for a compact explanation with the recommended default, consequence, common mistake where useful, and a local documentation reference.

The badge is not a substitute for clear labels. Guided mode should use plain language first. Advanced and Troubleshooting sections contain technical controls, diagnostics, and implementation details.

Help works offline because topics are bundled with the plugin in `pyforestscan_qgis/ui/help_topics.py`.
