# Height Above Ground (HAG)

## What It Measures

Point-cloud height normalization support and optional LAS/LAZ output.

## PyForestScan API Used

`read_lidar`, `add_height_above_ground`, `write_las`

## Key Parameters

CRS/SRS, DTM-backed HAG, DTM path, bounds, thinning radius, crop polygon, reproject, compress.

## When To Use

Use HAG workflows to normalize point heights or create reusable normalized point-cloud outputs.

## Output

The plugin writes the output into the active run folder or selected Processing Toolbox output path. Raster outputs are loaded into QGIS when requested; Rumple is written as CSV.

## Quality Checks

HAG output is LAS/LAZ when written; product rasters are generated by separate metric tools.

## Reproducibility

Record the input dataset, CRS, grid or voxel resolution, height thresholds, PyForestScan version, QGIS version, and plugin version when using this product in analysis.
