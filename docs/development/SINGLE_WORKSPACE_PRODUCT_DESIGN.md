# Single-Workspace Product Design

The default surface is **Process**. Its normal sequence is Processing Mode, LiDAR Data, Processing Area, Products, Output, synthesized readiness, and **Process LiDAR**. Progress replaces setup emphasis while running; Current Result exposes **Load into QGIS**, **Open Folder**, and **New Run** after success.

**Tools & Setup** is the only secondary destination. It contains a synthesized System status, environment verification, Processing Toolbox access, guidance details, output preferences, managed backend controls, and collapsed troubleshooting.

Legacy page widgets remain internal compatibility components and capability owners; they are not visible navigation destinations. SmartStatus is the normal source of readiness language. The four-widget footer is removed. Technical work-unit IDs, PIDs, heartbeats, retries, catalog controls, package details, and scientific signatures stay under Advanced or troubleshooting sections.
