# Future LiDAR Preparation Workbench

Phase 31A provides reusable assessment, planning, execution, quality, provenance, recommendation, and checkpoint services. A future workbench can call these boundaries from a 3D viewer/editor without placing scientific policy in UI controls.

Deferred capabilities include point viewing, selection/lasso, manual reclassification, ground editing, noise removal, CRS assignment, HAG/DTM creation, crop, merge, thinning, and prepared-LAZ export. The workbench must preserve source immutability and write the same provenance/signature contracts. No viewer or editor is implemented in Phase 31A.
