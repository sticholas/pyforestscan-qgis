# Automatic Job Recovery

Recovery removes invalid zero-byte temporary files while preserving the last valid state. A Running unit with a completed PBM result adopts that terminal result before new work begins. Circuit-breaker state is reconstructable. Normal users never choose a starting unit.


## Phase 28G Exact Polygon Completion

Recovery recomputes geometry membership, reclassifies excluded cores, verifies checksum/grid/core/HAG compatibility where recorded, re-signs compatible completions, and leaves required unfinished areas pending. Users never select a tile index.
