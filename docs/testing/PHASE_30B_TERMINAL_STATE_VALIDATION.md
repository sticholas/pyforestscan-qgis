# Phase 30B Terminal State Validation

Automated QGIS-free tests cover complete, success with warning, failed, cancelled, interrupted, recoverable, stale-running reconciliation, secondary failure, registration recovery, and auto-load warning semantics. Each terminal policy enables normal run inputs and disables pause/cancel.

The completion and failure handlers use finally-guarded cleanup. Durable errors are written before presentation. Terminal result items replace transient event items before Results and review refresh. A regression guard rejects any return of the removed `_batch_settings()` call.

Consecutive Job A to Job B live interaction, forced observer exceptions, coordinator disappearance, and QGIS auto-load failure remain in the live matrix because they require Qt/QGIS signal behavior. They must be run in a working QGIS Python environment before release approval.
