# Real LiDAR CRS And Map Action Validation

Live QGIS validation status must be recorded as Passed live, Failed live, or Not tested live for:

- Inspect Repository
- View Sources
- Add Coverage to Map
- Preview Spatial Selection
- Zoom to Polygon
- Zoom to Repository Extent
- Zoom to Combined Extent
- Assign Repository CRS
- Reread Headers
- Repair Spatial Index
- Re-run Preflight
- Reset Polygon Batch

Do not mark map actions passed from QGIS-free tests alone.
