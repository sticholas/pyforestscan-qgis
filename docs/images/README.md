# Documentation Images

This directory is reserved for screenshots used by user documentation.

Phase 5 screenshot placeholders:

- `dataset-explorer-toolbox.png`: Dataset Explorer listed in the QGIS Processing Toolbox.
- `dataset-explorer-dialog.png`: Dataset Explorer Processing parameters.
- `dataset-explorer-feedback.png`: Processing feedback with warnings and product feasibility.
- `dataset-explorer-csv-table.png`: Generated CSV summary loaded as a QGIS table.
- `dataset-explorer-html-report.png`: Generated HTML report opened in a browser.

Screenshots are intentionally not committed yet because they require an active
QGIS desktop session and representative sample data.
