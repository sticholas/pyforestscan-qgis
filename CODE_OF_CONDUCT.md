# Code of Conduct

PyForestScan QGIS aims to be a welcoming, professional, and scientifically
credible open-source project.

## Expected Behavior

- Be respectful and constructive.
- Welcome users with different levels of Python, QGIS, lidar, and ecology
  experience.
- Focus technical criticism on ideas, code, data, and documentation.
- Credit scientific methods, datasets, and prior work appropriately.
- Make room for careful review when changes affect scientific outputs.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Personal attacks or dismissive treatment of contributors.
- Publishing private information without consent.
- Misrepresenting scientific validity, authorship, or project endorsement.

## Reporting

Report conduct concerns privately to the project maintainers through the
preferred contact channel listed in the project repository. Maintainers should
respond with care, confidentiality, and proportional action.
